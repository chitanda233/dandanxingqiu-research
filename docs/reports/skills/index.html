版本 242 中 主动技能表有 8,237 行，被动技能表有 8,932 行。这些行包括测试、怪物、不同等级、隐藏效果与历史配置，不能说玩家可装备 8,237 种技能。表是从原始 Lua 5.1 字节码执行导出，中文名和说明由 主动语言表、被动语言表关联；脚本与哈希见导出清单。

如何读一行技能

常见字段：id 是具体等级/变体，prototype_id 是机制原型；effect 是一组按 index 排列的效果；cost 给费用种类和值；init_cd 初始冷却、turn_cd 回合冷却、turn_max 每回合次数、match_max 单局次数；pve_* 是 PVE 覆盖值。未填字段不能当作 0。-1 在诸多行表示没有配置限次，仍可能被战斗规则限制。原表

客户端 unit_can_use_skill 真实检查技能是否在角色持有列表中、当前回合与行动状态、沉默、定身/位移、重复回合、turn_max、match_max、CD、禁用类型和费用。技能实际效果与资源扣减由服务端回包推进。校验调用

例如 搬砖水泥桶 系列：2110011 基础档双子弹，每颗说明为 17.6%+2，CD 2；2110021 真档 19.4%+3；2110031 极档 23.2%+3；2110041 绝档 25.6%+4；2110051 超档 27.6%+条件加成 3.1%+5；2110061 神档 30%+条件加成 5.3%+6。效果字段分别含 100 比例、101 固定项、8=1（第二发的索引从 0 起）与 61.jellyfish_info 两枚偏角 ±5 的子弹配置。技能表

许愿魔杖 2126011 一发信号弹 25.6%+6，再召流星 76.8%+20；真档 2126021 为 28.2%+7 / 84.5%+23；极档 2126031 为 33.8%+9 / 101.4%+28；绝档 2126041 为 37.2%+10 / 111.5%+31。这里的“多段总伤”不能简单相加，因为目标选择、命中、暴击和独立伤害事件要由战斗节点确认。技能表

被动技能不是一张增伤百分比表

被动表效果形态包括 ps_add_buff、ps_add_energy、ps_add_anger、ps_check_obj_num 等。例：ID 2 的 ps_add_energy={prob:10000,add_value:50}，ID 3 的 ps_add_anger 同值；其中 10000 可能是万分比基数，但需通过实际触发器确认。ID 4/5 的 ps_check_obj_num 限定空间宽高、阵营、数量再加分。被动可以改资源、状态、召唤物与触发条件，不是只改攻击乘区。被动表

数值字段的适用边界

技能 effect.100 常与文字中的伤害率×100 相合，如 2005233 的 12050 对应 120.5%；effect.101 常是固定项。但这仅说明该技能字段的编码，不能推出最终伤害公式。技能触发后还会进入伤害、命中、暴击、护盾、目标状态、PVP 平衡和服务器节点链。更完整的输入与轨迹见局内计算。
