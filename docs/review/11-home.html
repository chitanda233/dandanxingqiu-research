家园与职业

方案编辑、复制、制造、魅力与访问

版本 2422026.10.01 复查原文件可追溯

一套可编辑、可访问的场景系统

家园维护方案、地形、家具/摆放物、区域、职业、制造、魅力、照片、访问和聚会。农场位于相关场景体系，但有独立土地、作物与订单状态，后章单独说明。切换家园、回自己的家园、重新进入以及场景内区域归属有不同处理。家园管理器

布置方案与编辑操作

摆放、更换、移除物品，替换/擦除地形，预览和保存方案是不同操作。需要区分物品所有权、库存数量、当前已摆放实例、当前预览和保存后的方案。多个方案允许玩家在保留库存的同时切换布局；复制他人方案又增加缺料检查与购买提示。

杂项配置有 5 个方案、复制费用家园币 1160020001×100、每日被复制上限3等原值。复制资格、私密设置和目标预览需先确认；本地预览并不已经扣币或保存。家园杂项

复制他人方案的完整链

请求目标方案 → 获取预览和已摆放物 → 比较自己缺失物品 → 展示缺料/购买路径 → 确认继续 → 提交复制 → 成功后更新方案。try_continue_duplicate_plan_from_other_preview 与最终继续复制是分开的。预览 URL 缺失也有独立查询，不能只复制页面截图来代表可编辑布局。

家园复制还支持发送私聊消息，但本次报告生成没有向用户好友发任何消息。这里描述的是游戏内部功能，不是要求研究工具执行社交动作。复制原函数

三种职业与职业升级

职业表有园丁、工匠、厨师。杂项配置职业更换参数14天。职业等级提升检查上限、下一行、魅力要求与第一项消耗材料余额；编辑器 GM 分支不能推广为普通玩家免费升级。职业表 升级原函数

职业每日奖励、职业升级、帮助制造和魅力奖励有各自红点。制造需要目标物、进度和帮助对象；走到目标后帮助、取消前往目标的处理也分开。help manufacture factor=13333 是原参数，未沿所有制造使用处验证前不直接宣称某个实际提速百分比；每周帮助5次亦应按实际额度数据使用。

魅力奖：三态与初始化边界

get_charm_reward_state 返回 0未达、1可领、2已领。魅力99/阈值100返回0；魅力100且未领返回1；在已领列表中返回2。即使魅力足够，如果领取列表尚为 nil，该函数也返回0，所以数据未初始化不能自动亮可领奖。魅力原函数

魅力可以作为职业与奖励门槛，但本次没有闭合所有家具评分、重复摆放折算和服务端反重复规则。不能仅把每件家具 charm 字段加总就称最终魅力。

照片、点赞、访问与聚会

照片数据与“已查看照片”本地标志分开；保存、展示与点赞还有自己的请求和记录。杂项有点赞日上限100、场景人数10等原值。派对、绘画房间、观看、重连和回自己家园各有分支；人数参数不应自动套到所有子房间。家园房间

设计分析与复刻要点

家园通过布局方案提供表达空间，通过职业与制造提供成长，通过访问/照片/复制/帮助提供关系行为。复制功能让高完成度布局可传播，但需要库存与成本约束。复刻应优先保留可编辑数据、预览/保存区分、库存占用、访问权限、帮助目标状态、领取三态和重连；先做截图展示无法覆盖这些业务机制。
